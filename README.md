# 경사하강법 시뮬레이터

학습률(α)을 바꿔 가며 공의 움직임을 관찰하는 교육용 웹사이트예요.
서버·데이터베이스·로그인 없이 **브라우저에서만** 동작하는 정적 사이트라서 GitHub Pages로 바로 배포할 수 있어요.

| 모드 | 하는 일 |
|---|---|
| 게임모드 | 축구공 애니메이션, 퀘스트·XP·보상, 결과별 특수효과(거북이·번개·핑퐁·폭발) |
| 연구자모드 | 2차/4차 선택 → 각 3종 함수 선택 → 실험. 실험 후 **이동 경로 점선**, Loss 변화 그래프, **학습률 비교 실험실**, 관찰 가이드 |

## 바로 열어 보기

- `index.html`을 더블클릭해도 열려요(`file://` 지원).
- 로컬 서버로 보려면: `python3 -m http.server 8000` 후 `http://localhost:8000` 접속.

## GitHub Pages 배포

1. 이 폴더의 파일 전체를 GitHub 저장소 루트에 올려요(`index.html`이 루트에 있어야 해요).
2. 저장소 **Settings → Pages → Build and deployment**에서 *Deploy from a branch*를 고르고, 브랜치 `main`, 폴더 `/ (root)`를 선택해요.
3. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 에서 열려요.

모드 주소는 `#`을 쓰기 때문에 새로고침이나 직접 접속도 그대로 동작해요.

| 주소 | 화면 |
|---|---|
| `/#/` | 첫 화면 |
| `/#/game` | 게임모드 |
| `/#/research` | 함수 차수 선택 |
| `/#/research/quadratic` | 2차함수 3종 선택 |
| `/#/research/quartic` | 4차함수 3종 선택 |
| `/#/research/quartic/F04` | 선택한 함수의 연구 실험실 |
| `/#/challenge` | 통합 연구자모드로 연결(이전 주소 호환) |

`.nojekyll` 파일이 들어 있어서 GitHub가 폴더를 따로 가공하지 않아요.

## 데이터는 어디에 저장되나요?

- 실험 기록과 게임 진행 상황은 **이 브라우저의 LocalStorage**에만 저장돼요.
- 서버로 보내지 않고, 다른 사람의 기록과 합치지 않아요. 통계 수집 기능도 없어요.
- 브라우저 데이터를 지우거나 다른 기기를 쓰면 기록이 보이지 않아요. 보관하고 싶다면 각 화면의 **CSV 내려받기**를 쓰세요.
- LocalStorage를 쓸 수 없는 환경(시크릿 모드 등)에서는 화면을 닫기 전까지만 유지된다고 안내해요.

## 함수 추가하기

`assets/js/core/functionRegistry.js`의 `FUNCTION_DEFS`에 항목 하나만 추가하면, 연구자모드 함수 선택·그래프·기록에 반영돼요.
화면 코드는 고치지 않아도 돼요.

```js
{
  id: 'F07', name: '새 함수', expr: 'f(x) = x² + 1', dexpr: 'f′(x) = 2x',
  f: x => x * x + 1, df: x => 2 * x, d2f: () => 2,        // 함수값·도함수·이계도함수
  view: { xMin: -5, xMax: 5 },                              // 그래프 기본 범위
  start: { default: 4, options: [-4, 4], min: -5, max: 5 },
  alpha: { min: 0.05, max: 1.5, step: 0.05, default: 0.5 },
  iterations: { min: 1, max: 20, default: 10 },
  tolX: 1e-5,                                               // 성공 판정 오차
  compareAlphas: [0.2, 0.5, 0.8, 1.0, 1.2],
  feature: '…', goal: '…', probe: '…',
  guide: [['조건', '관찰되는 현상', '해석']]
}
```

일반 함수의 극솟값·극댓값은 도함수의 부호 변화를 이용해 계산해요. 도함수에 중근이 있어 부호가 바뀌지 않는 수평변곡점은 `stationaryXs`(예: `[0, 2]`)에 두 정지점 위치를 명시해 정확하게 표시하고, 좌우의 부호로 극솟값과 구분해요.
추가한 뒤 `node tests/core.test.js`로 도함수가 맞는지 확인하세요.

## 알려 둘 점

- 글꼴(Jua, Noto Sans KR)은 Google Fonts에서 불러와요. 연결이 없으면 기기 기본 한글 글꼴로 대체돼서 화면은 그대로 동작해요.
- 게임모드의 효과·이모지는 이전 버전의 모습을 그대로 유지해요. 기기에 따라 이모지 모양이 조금 다를 수 있어요.
- 기기의 "동작 줄이기" 설정을 켜면 번쩍이는 효과와 부드러운 이동 대신 단계별 점프로 보여 줘요.
- 이번 범위에서 제외한 기능: 실시간(애니메이션 중) 계산식 표시, 기울기/접선 시각화, 삼차함수, 임의 함수 입력, 참여자 통계, 로그인, 서버. Loss 점 클릭 시에는 단계별 계산식을 표시해요.

## 연구자모드 추가 기능 (2026-11 업데이트)

1. **학습률 정밀/확장 범위 전환**: 4차함수에서 기본 정밀 범위(F04 0.01~1.5, F05 0.005~0.2, F06 0.005~0.12)를 이용하고, 발산 등 고학습률 실험이 필요할 때 **확장 범위**(각 함수 최솟값~30)로 바꿔요. 숫자 입력은 슬라이더 눈금과 관계없이 입력한 소수 값을 그대로 계산에 사용해요. 2차함수의 학습률 범위는 그대로 유지해요.
2. **단계별 CSV 다운로드**: 연구자모드에서 실험 후 **단계별 데이터 CSV**를 누르면 각 n의 위치 `xₙ`, 기울기 `f′(xₙ)`, `Loss`, 다음 위치, 이동량, Loss 변화와 종료 사유를 내려받을 수 있어요. 발산 제한으로 값이 잘린 경우에는 별도로 표시해요. 엑셀 한글 호환을 위해 UTF-8 BOM을 포함해요.
3. **비교 실험 단계별 CSV**: 학습률 비교 실험을 실행하면 선택한 모든 학습률의 단계별 데이터를 **하나의 CSV 파일**로 받는 버튼이 생겨요.
4. **재생 속도**: 연구자모드 그래프에서 **0.5배속·1배속·2배속·4배속** 중 선택할 수 있어요. 재생 도중 바꿔도 바로 반영되고 다시 보기에도 유지돼요. 게임모드 애니메이션에는 영향을 주지 않아요.
5. **모바일 안내문**: 이전에 그래프 가운데를 가리던 안내를 그래프 **아래쪽 정보줄**로 옮겼어요. 640px 이하 화면에서는 조작 안내도 줄여서 표시하고, 속도 선택은 터치하기 쉬운 크기로 유지해요.

기존 **함수 5종 전환, Loss 그래프, 확대·축소·시작 위치 반영, 게임모드, 기록 관리** 기능은 유지해요.

## 이번 버전 변경 사항

- 사이트는 **게임모드 + 연구자모드** 두 가지예요. 이전 `#/challenge` 주소는 연구자모드 첫 단계로 연결돼요.
- 연구자모드에서 **2차 또는 4차 선택 → 그래프 미리보기가 있는 3종 함수 선택 → 실험** 순서로 이동해요.
- 연구자모드에서 2차함수의 학습률 상한은 F01 **1.5**, F02 **2**, F03 **0.3**이고, 4차함수의 학습률은 **최대 30**이에요. 게임모드 설정 범위는 그대로예요.
- 최대 반복 횟수는 **기본 포물선 10회 / 나머지 2차 20회 / 4차 30회**예요.
- 4차함수 3종: **깊이가 다른 두 골짜기(F04)**, **수평변곡점과 하나의 극솟값(F05)**, **U자형(F06)**.
- 연구자모드 진입 시에는 차수(2차·4차) → 함수 모양을 순서대로 선택해요. **실험 화면의 함수 설정을 열면 현재 함수를 제외한 5종이 2차·4차로 묶여 나오며**, 차수가 달라도 즉시 이동하고 그 함수에 맞는 시작점·학습률·반복 횟수·관찰 가이드가 적용돼요.
- 시작 위치 수치·슬라이더·선택 버튼을 바꾸면 실험 전 그래프의 출발 공도 즉시 움직여요.
- 함수 그래프는 **마우스 휠·드래그·모바일 두 손가락**으로 확대·축소·이동할 수 있고, **원래 화면 아이콘**으로 다시 맞출 수 있어요.
- 학습률 빠른 선택 버튼은 제거했어요.
- 관찰 가이드는 첫 이동 계산과 **n = 0~4 수치 검증 표**, 수렴·왕복·발산 판단 기준을 보여 줘요.
- **Loss 변화 그래프 및 학습률 비교 Loss 그래프**에서 점을 누르면 수식 대입 결과를 볼 수 있어요.
- 게임모드의 발산 연출은 **💣 ↗️**로 표시하며, 원래의 **게임 기록·XP·퀘스트 전체 초기화**가 유지돼요.
- 이전 도전모드에 저장했던 브라우저 기록은 삭제하거나 연구자 기록으로 자동 변환하지 않아요.
